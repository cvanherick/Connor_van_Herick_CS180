Part 1.1: Convolution Comparison

Implementations

Both implementations perform same-sized 2D convolution using NumPy. The kernel is flipped before multiplying so the operation is true convolution rather than correlation.

def convolve_four_for_loops(image, kernel):
    image_height, image_width = image.shape
    filter_height, filter_width = kernel.shape

    pad_h = filter_height // 2
    pad_w = filter_width // 2
    padded_image = np.pad(
        image,
        ((pad_h, pad_h), (pad_w, pad_w)),
        mode="constant",
        constant_values=0
    )

    output = np.zeros((image_height, image_width))
    kernel = np.flip(kernel)

    for i in range(image_height):
        for j in range(image_width):
            total = 0
            for u in range(filter_height):
                for v in range(filter_width):
                    total += padded_image[i + u, j + v] * kernel[u, v]
            output[i, j] = total

    return output
def convolve_two_for_loops(image, kernel):
    filter_height, filter_width = kernel.shape
    image_height, image_width = image.shape

    pad_h = filter_height // 2
    pad_w = filter_width // 2
    padded_image = np.pad(
        image,
        ((pad_h, pad_h), (pad_w, pad_w)),
        mode="constant",
        constant_values=0
    )

    output = np.zeros((image_height, image_width))
    kernel = np.flip(kernel)

    for i in range(image_height):
        for j in range(image_width):
            patch = padded_image[i:i + filter_height, j:j + filter_width]
            output[i, j] = np.sum(patch * kernel)

    return output

Comparison and runtime

The NumPy result is compared with scipy.signal.convolve2d using mode="same", boundary="fill", and fillvalue=0. The comparison uses np.allclose to verify that the outputs agree.

Both scratch implementations have runtime O(HWkhkw). The four-loop version performs every multiplication and addition in Python, while the two-loop version lets NumPy handle each patch operation in optimized compiled code, making it faster in practice. SciPy is generally faster still because its convolution implementation is optimized compiled code.

Boundary handling

The image is padded with zeros before filtering. Padding by half the kernel height and width preserves the original image dimensions, which corresponds to SciPy’s same mode with zero-filled boundaries.
