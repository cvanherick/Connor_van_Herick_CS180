Four nested loops

def convolve_four_for_loops(image, kernel):
    image_height, image_width = image.shape
    filter_height, filter_width = kernel.shape

    pad_h = filter_height // 2
    pad_w = filter_width // 2
    padded_image = np.pad(
        image,
        ((pad_h, pad_h), (pad_w, pad_w)),
        mode="constant",
        constant_values=0
    )

    output = np.zeros((image_height, image_width))
    kernel = np.flip(kernel)

    for i in range(image_height):
        for j in range(image_width):
            total = 0
            for u in range(filter_height):
                for v in range(filter_width):
                    total += padded_image[i + u, j + v] * kernel[u, v]
            output[i, j] = total

    return output

Two nested loops

def convolve_two_for_loops(image, kernel):
    filter_height, filter_width = kernel.shape
    image_height, image_width = image.shape

    pad_h = filter_height // 2
    pad_w = filter_width // 2
    padded_image = np.pad(
        image,
        ((pad_h, pad_h), (pad_w, pad_w)),
        mode="constant",
        constant_values=0
    )

    output = np.zeros((image_height, image_width))
    kernel = np.flip(kernel)

    for i in range(image_height):
        for j in range(image_width):
            patch = padded_image[i:i + filter_height, j:j + filter_width]
            output[i, j] = np.sum(patch * kernel)

    return output

Correctness, runtime, and boundaries

To check correctness, the two-loop NumPy implementation is compared with scipy.signal.convolve2d using matching settings:

reference = scipy.signal.convolve2d(
    image,
    kernel,
    mode="same",
    boundary="fill",
    fillvalue=0
)
assert np.allclose(convolve_two_for_loops(image, kernel), reference)

Both scratch implementations have runtime O(HWkhkw) for an image of size H × W and a kernel of size kh × kw. The four-loop version performs every multiplication and addition in Python. The two-loop version still iterates over image locations in Python, but uses NumPy for each padded patch and elementwise multiplication, so it is faster in practice. SciPy is typically fastest because its convolution routine is implemented in optimized compiled code.

For boundary handling, the image is padded with zeros by half the kernel height and width. This keeps the output the same size as the input and matches convolve2d(..., mode="same", boundary="fill", fillvalue=0).

Part 1.3: Derivative of Gaussian (DoG) Filter

The finite-difference results contain noticeable noise, so I first smoothed the cameraman image with a 9 × 9 Gaussian filter created from cv2.getGaussianKernel(9, 2) and its transpose. After smoothing, I recomputed the derivatives and gradient magnitude.

For the smoothed gradient image, I used a threshold of 20. Gaussian smoothing suppresses small variations, so a lower threshold recovers meaningful edges that would be missed by the threshold of 65 used on the noisier finite-difference result.

Instead of smoothing and then applying two derivative convolutions, I also formed derivative-of-Gaussian filters by convolving the Gaussian with D_x and D_y. The resulting full-support filters are shown below.

G_1d = cv2.getGaussianKernel(9, 2)
G_2d = G_1d @ G_1d.T
camera_blurred = convolve_two_for_loops(camera_image, G_2d)

DoG_x = convolve2d(G_2d, Dx, mode="full", boundary="fill", fillvalue=0)
DoG_y = convolve2d(G_2d, Dy, mode="full", boundary="fill", fillvalue=0)
dog_dx = convolve_two_for_loops(camera_image, DoG_x)
dog_dy = convolve_two_for_loops(camera_image, DoG_y)

The Gaussian-smoothed gradient and the single-convolution DoG gradient agree away from the outer zero-padding boundary. The remaining differences are concentrated at the border because the two-step and one-step versions encounter the image boundary differently. In the interior, the DoG filters reproduce the same edge structure while requiring only one convolution per derivative direction.

Part 2.1: Image “Sharpening”

An unsharp mask sharpens an image by emphasizing the high-frequency details that are reduced by blur. I first convolve the grayscale image with a 9 × 9 Gaussian filter to create a blurred, low-frequency version. Subtracting this blurred image from the original isolates the high-frequency residual, which contains edges and fine texture. Adding a scaled version of that residual back to the original produces the sharpened image.

blurred = convolve_two_for_loops(image, gaussian_filter)
high_frequency = image - blurred
sharpened = np.clip(image + alpha * high_frequency, 0, 255)

Equivalently, the code combines the identity impulse filter and the Gaussian filter into one unsharp filter: (1 + alpha)I - alpha G. Here, alpha controls the sharpening strength. I compare alpha = 1, 2, and 4; larger values increase edge contrast but can also exaggerate noise, halos, and clipping.

Part 2.2: Hybrid Images

A hybrid image combines the low frequencies of one aligned image with the high frequencies of another. I create the low-frequency component by Gaussian-blurring the second image. For the high-frequency component, I subtract a Gaussian-blurred version of the first image from the original. Adding the two filtered components produces an image that changes appearance with viewing distance: nearby, the high-frequency image is more visible; farther away, the low-frequency image dominates.

low_frequency = blur_image(low_image, sigma_low)
high_frequency = high_image - blur_image(high_image, sigma_high)
hybrid = np.clip(low_frequency + high_frequency, 0, 1)

For the Lionel Messi/Lion example, I chose sigma_high = 6 and sigma_low = 8 after comparing several cutoff pairs. The experiment below compares (4, 6), (6, 8), and (8, 10). The middle setting preserves enough facial detail while keeping the low-frequency lion visible.

The images were aligned by selecting two corresponding points in each image, using the eyes as landmarks before filtering.

Part 2.3: Gaussian and Laplacian Stacks

A stack keeps every level at the original image dimensions. I built the Gaussian stack by repeatedly applying a 9 × 9 Gaussian filter with sigma = 8 without downsampling. Each Laplacian level is the difference between two neighboring Gaussian levels, with the final Gaussian level stored as the low-frequency residual.

gaussian_levels = gaussian_stack(image, 4)
laplacian_levels = laplacian_stack(gaussian_levels)

# No pyrDown or pyramid_gaussian is used:
next_level = blur_image(previous_level)

For the Oraple, I used a left-half mask for the apple and a right-half mask for the orange. I blurred the mask at every stack level, combined the corresponding Laplacian levels, and summed the combined stack to reconstruct the final image. Blending at multiple frequencies avoids the hard seam produced by directly joining the two originals.

Part 2.4: Multiresolution Blending

I started with a vertical-seam blend of a lion and a tiger. Both images are center-cropped to a shared square canvas, then a left-half step mask selects the lion and the right half selects the tiger. The mask is blurred at every Gaussian-stack level so the final seam changes gradually instead of creating a hard edge.

mask = vertical_mask(lion.shape)
mask_stack = gaussian_stack(mask, 4)
