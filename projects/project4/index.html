A.2 · Recover Homographies

For each pair, I manually select ten corresponding points. A 3 × 3 homography maps image 1 coordinates (x, y) to image 2 coordinates (u, v), with h₃₃ fixed to 1.

u = (h11 x + h12 y + h13) / (h31 x + h32 y + 1)
v = (h21 x + h22 y + h23) / (h31 x + h32 y + 1)

For each match (x, y) → (u, v):
[x y 1 0 0 0 -ux -uy] h = u
[0 0 0 x y 1 -vx -vy] h = v

h = [h11 h12 h13 h21 h22 h23 h31 h32]ᵀ
Ah = b;  A ∈ R^(20×8), b ∈ R^20
h = numpy.linalg.lstsq(A, b, rcond=None)[0]

Ten matches give an overdetermined system with twenty equations and eight unknowns. Least squares minimizes the squared algebraic residual. The matrices and point downloads below use the original image coordinates; the website previews are resized for display.

A.3 · Warp the Images

Both implementations use inverse warping. I transform the source image’s four corners to determine the output bounds, then map each output pixel back through H⁻¹. Coordinates outside the source image remain black.

[xs, ys, w]ᵀ = H⁻¹ [xout, yout, 1]ᵀ
(x, y) = (xs / w, ys / w)

Nearest neighbor: sample at (round(x), round(y)).

Bilinear: x0 = floor(x), y0 = floor(y)
dx = x - x0; dy = y - y0
I(x, y) = (1-dx)(1-dy) I[y0, x0]
        + dx(1-dy) I[y0, x0+1]
        + (1-dx)dy I[y0+1, x0]
        + dx dy I[y0+1, x0+1]

At the final source row or column, neighbor indices are clamped to the image boundary. Nearest-neighbor and bilinear interpolation are implemented directly in warpImageNearestNeighbor and warpImageBilinear.

Interpolation trade-offs

MethodSampling workImage quality
Nearest neighborOne source pixel per output sample; less interpolation work.Preserves individual source values but can introduce jagged edges and aliasing.
BilinearFour source pixels and a weighted average; more interpolation work.Smoother edges, with some softening of fine detail.

Both methods produce the same projective geometry. Their sampling differences are subtle at this display scale; interpolation does not correct inaccurate point matches or parallax. The speed comparison above describes computational work, not measured runtimes.
