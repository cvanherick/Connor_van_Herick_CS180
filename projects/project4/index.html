A.2 · Recover Homographies

For each pair, I manually select ten corresponding points. A 3 × 3 homography maps image 1 coordinates (x, y) to image 2 coordinates (u, v), with h₃₃ fixed to 1.

u = (h11 x + h12 y + h13) / (h31 x + h32 y + 1)
v = (h21 x + h22 y + h23) / (h31 x + h32 y + 1)

For each match (x, y) → (u, v):
[x y 1 0 0 0 -ux -uy] h = u
[0 0 0 x y 1 -vx -vy] h = v

h = [h11 h12 h13 h21 h22 h23 h31 h32]ᵀ
Ah = b;  A ∈ R^(20×8), b ∈ R^20
h = numpy.linalg.lstsq(A, b, rcond=None)[0]

Ten matches give an overdetermined system with twenty equations and eight unknowns. Least squares minimizes the squared algebraic residual. The matrices and point downloads below use the original image coordinates; the website previews are resized for display.

A.3 · Warp the Images

Both implementations use inverse warping. I transform the source image’s four corners to determine the output bounds, then map each output pixel back through H⁻¹. Coordinates outside the source image remain black.

[xs, ys, w]ᵀ = H⁻¹ [xout, yout, 1]ᵀ
(x, y) = (xs / w, ys / w)

Nearest neighbor: sample at (round(x), round(y)).

Bilinear: x0 = floor(x), y0 = floor(y)
dx = x - x0; dy = y - y0
I(x, y) = (1-dx)(1-dy) I[y0, x0]
        + dx(1-dy) I[y0, x0+1]
        + (1-dx)dy I[y0+1, x0]
        + dx dy I[y0+1, x0+1]

At the final source row or column, neighbor indices are clamped to the image boundary. Nearest-neighbor and bilinear interpolation are implemented directly in warpImageNearestNeighbor and warpImageBilinear.

Interpolation trade-offs

MethodSampling workImage quality
Nearest neighborSamples one pixel per output pixel, making it faster.Can produce jagged edges and aliasing.
BilinearUses a weighted average of four neighboring pixels, requiring more computation.Produces smoother results but can slightly blur fine details.

Both interpolation methods use the same homography, so the underlying geometry is identical. The main difference is how pixel values are calculated. In my examples, the visual differences are relatively small, although bilinear interpolation generally produces smoother results.

A.4 · Blend Images into a Mosaic

I first warp image 1 into image 2's coordinate system using the calculated homography. I then create a canvas large enough to fit both images and use inverse warping with bilinear interpolation to map the pixels. I also create masks to keep track of which pixels are valid in each image.

For the overlapping regions, I use distance-based weighting to blend the images together. Pixels closer to the edge of an image receive less weight, which creates a smoother transition between the two images. Any black regions correspond to areas where neither image has valid pixels.

Part B · Automatic Image Stitching

I use the same Hawaii, Bedroom, and Kitchen pairs from Part A. Harris corners and ANMS select feature locations; normalized patches provide descriptors; ratio-test matches and four-point RANSAC estimate each homography.

B.1 · Harris Corner Detection and ANMS

The left column in each figure shows the detected Harris corners on both input images. Adaptive non-maximal suppression ranks each point by its distance to a sufficiently stronger corner and retains 250 spatially spread points per image, shown at right.

B.2 · Feature Descriptor Extraction

At each retained corner, I blur a 40 × 40 grayscale patch, sample every fifth pixel to obtain an axis-aligned 8 × 8 descriptor, then subtract its mean and divide by its standard deviation. Each row below shows six normalized features from one image.

B.3 · Feature Matching

I compare descriptor distances and accept a match when the nearest-neighbor distance divided by the second-nearest distance is below 0.6. Each figure shows those matches above and the RANSAC inliers below.

B.4 · RANSAC for Robust Homography

For each pair, four-point RANSAC samples candidate homographies for 2,000 iterations and counts matches within a 4-pixel reprojection error. I recompute the homography from the best inlier set, then use the Part A warping and blending procedure to make an automatic mosaic.

The three comparisons below place the manually stitched Part A result beside the automatically stitched Part B result. The automatic alignment is close to the manual alignment in each scene, with small differences at the image boundaries and overlaps.
